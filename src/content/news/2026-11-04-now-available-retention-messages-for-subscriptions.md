Apple 宣布订阅挽留消息（Retention messages for subscriptions）现已推出。该功能旨在减少取消，在订阅者决定是否取消时，通过挽留消息提醒其订阅的价值。

## 展示形式

挽留消息会出现在取消流程中，可包含文字、图片或特别优惠。

## 配置与 API

- 在 App Store Connect 中，开发者可为自动续期订阅配置挽留消息，包括订阅者资格以及两次优惠之间的等待时间。
- 通过 Retention Messaging API，开发者可根据订阅者的订阅详情，选择向每位订阅者展示哪条消息。
- API 访问需提出申请。
