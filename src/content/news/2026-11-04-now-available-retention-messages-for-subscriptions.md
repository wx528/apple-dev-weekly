Apple 宣布订阅留存消息（Retention messages for subscriptions）现已推出。该功能旨在减少取消订阅，在订阅者决定是否取消时，向其提醒订阅的价值。

## 功能说明

留存消息会出现在取消流程中，内容可以包含文本、图片或特别优惠。

## 配置与 API

- 在 App Store Connect 中，开发者可为自动续期订阅配置留存消息，包括订阅者资格以及消息之间的等待时间。
- 通过 Retention Messaging API，开发者可根据订阅者的订阅详情，选择向每位订阅者展示哪条消息。
- API 访问需申请开通。
